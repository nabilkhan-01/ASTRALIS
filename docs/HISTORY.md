# ASTRALIS History

## 2026

### v0.0.1 — Genesis
- Project created.
- Core architecture established.
- Engineering principles documented.

### v0.1.0 — Foundation
- Core Engine completed.
- Brain architecture introduced.
- Provider abstraction implemented.
- Interactive command-line interface added.

### First AI Conversation
ASTRALIS successfully completed its first real conversation using the Gemini API.

This milestone demonstrated the complete request processing pipeline:

CLI → Brain → Provider → Gemini → Response

### Conversation Architecture
ASTRALIS introduced provider-independent conversation management.

The Brain became the owner of conversation state while AI providers became stateless language engines.

This established the foundation for interchangeable providers and future capabilities without changing the Brain.
