# ASTRALIS History

## 2026

### v0.0.1 — Genesis

- Project created.
- Core architecture established.
- Engineering principles documented.
- Project vision and long-term roadmap defined.

---

### v0.1.0 — Foundation

- Core Engine completed.
- Brain module introduced.
- Modular application architecture established.
- Interactive command-line interface implemented.

---

### First AI Conversation

ASTRALIS successfully completed its first real conversation using the Gemini API.

This milestone validated the complete request-processing pipeline:

CLI → Brain → Provider → Gemini → Response

---

### Conversation Architecture

Conversation ownership moved into the Brain.

AI providers became stateless language engines that operate only on the supplied conversation, establishing provider-independent conversation management.

---

### v0.2.0 — Brain Architecture

ASTRALIS evolved from direct provider-based execution to a capability-based architecture.

Major milestones included:

- Request interpretation through the Interpreter.
- Execution planning through the Planner.
- Provider-independent conversation management.
- Introduction of the Capability Framework.
- Capability Manager and Capability Registry.
- Language Capability as the first executable capability.
- Brain refactored into an orchestration component.
- AI providers fully decoupled from Brain execution.

This milestone established the architectural foundation for future capabilities including Memory, Browser, Vision, Automation, and eventually the ASTRALIS Language Model.
